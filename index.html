⚙️ First time? Quick Firebase Setup (free, 5 min):

  1. Go to console.firebase.google.com
  2. Click Add project → name it "Rental Manager" → Create
  3. Click Web icon (</>) → Register app → copy the firebaseConfig
  4. Open this HTML file in a text editor → find FIREBASE_CONFIG → paste your values
  5. In Firebase console → Authentication → Sign-in method → enable Google
  6. In Firebase console → Firestore Database → Create database → Start in test mode
  7. Save the file and reload — sign in with Google and your data syncs everywhere!
